# 寶光崇正 2027 年度整合行事曆

這是純靜態前端，資料即時讀取 Google Apps Script Web App API，適合直接使用 GitHub Pages。

## 資料流程

1. 在 Google Sheet 的 `2027年度_月曆報表` 修改活動。
2. 在試算表選單選擇 `寶光行事曆工具 → 一鍵更新網頁＋Google公版日曆`。
3. 網頁重新整理後讀取最新資料；Google 公版日曆會在背景分批完成差異同步。

若只想更新網站而不變動 Google 公版日曆，可選擇 `僅建立／更新網頁資料`。

## Google 公版日曆同步

- 日曆名稱：`寶光崇正2027年度全球行事曆`
- Apps Script 原始碼：`apps-script/Code.gs`
- 日曆 ID 不寫入公開原始碼，而是透過試算表選單 `設定Google公版日曆ID` 儲存在 Apps Script 私人的 Script Properties。
- 同步方式：以 `event_id` 建立索引，只新增、修改或刪除有差異的活動，不會每次重複建立全部事件。
- v1.4.3 起，同一天若在年度總表分成多列，第一筆保留既有 ID，後續活動加入來源列識別，避免不同活動互相覆蓋。
- v1.4.4 修正「系統設定」的 `event_count` 被舊日期格式顯示成 1905 年日期的問題。
- 大量活動會每批處理 60 筆，並以一分鐘後的單次觸發器自動接續，避免 Apps Script 執行逾時。
- 每批最多執行 60 次實際寫入；已同步且未變更的活動會快速略過，因此補漏不必重新等待完整批次。
- 完成時以成功寫入索引數驗收；如遇 Google 暫時限流或個別寫入失敗，會顯示實際缺漏數並最多自動重試三輪，不會再把「已掃描」誤報成「已完成」。
- 第一次執行會要求 Google 日曆存取權限；授權帳號必須是該公版日曆的擁有者或具備修改權限。
- `Google日曆同步索引` 工作表由程式維護並自動隱藏，請勿手動刪除或修改。
- 可用 `查看Google日曆同步狀態` 查看目前進度；如背景觸發器中斷，可按 `繼續Google日曆同步`。

目前公版日曆先維持私人。是否公開活動內容、以及網站上的「加入公版行事曆」按鈕，應在確認首輪同步資料正確後再啟用。

## 加入個人行事曆

- 前端「加入我的行事曆」提供 Google 日曆與 iPhone／Apple 日曆兩種訂閱入口。
- 採用唯讀訂閱，不複製 1,865 筆活動，也不讀取、上傳或顯示使用者的私人行程。
- 公版日曆更新後，訂閱者會由 Google 或 Apple 日曆服務自動取得更新；實際更新時間由各平台決定。
- Apple 的公開 ICS 訂閱必須先將公版日曆设为公开；Google 日曆若維持私人，則只有已獲分享權限的帳號能加入。

首次安裝或升級至 v1.4.4 後，請先重新整理試算表，依序執行：

1. `寶光行事曆工具 → 設定Google公版日曆ID`
2. `寶光行事曆工具 → 一鍵更新網頁＋Google公版日曆`

## GitHub Pages

儲存庫的 Pages 來源請設定為 `Deploy from a branch`，Branch 選 `main`，資料夾選 `/ (root)`。

## API

API 網址設定於 `app.js` 最上方的 `API_URL`。目前使用 Apps Script JSONP，避免 GitHub Pages 跨網域讀取限制。

## Apps Script 日期修正

若 API 的 `dateDisplay` 或 `lunar` 顯示為 `2026-10-01T16:00:00.000Z`，請更新至資料建置程式 v1.2、重新執行資料建置，並將 Web App 建立「New version」後重新部署。前端已加入相容性防護，但資料層仍建議完成修正。
